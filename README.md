# HKSO Mechanical Keyboards Storefront

A responsive e-commerce landing page featuring custom styling, a product grid showcasing premium mechanical keyboards, and engaging user interactivity.

# 📁 Project Structure

```text
├── index.html     # Structural markup (Header, About Us, Products Grid, Footer)
├── style.css      # Custom visual layouts, layout alignments, transformations, and hover dynamics
└── script.js     # DomContentLoaded event handling and window scroll actions

# 🛠️ Setup Instruction

1. **Clone or Download**: Save `index.html`, `style.css`, and `script.js` directly in the same root folder on your local machine.
2. **Add Assets**: Place your visual identity and asset images inside the root folder:
   - `hkso-logo.jpg` (Header logo)
   - `team-photo.jpg` (About section image)
   - `keyboard-1.jpg`, `keyboard-2.jpg`, `keyboard-3.jpg` (AI-generated product images)
3. **Execution**: Open `index.html` inside any modern browser (Chrome, Edge, Safari, Firefox) to view and test the interface natively.
